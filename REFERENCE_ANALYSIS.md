# Reference Analysis

This repository follows the useful pattern from `WinterDDo/paul-graham-skills`: separate human principles from agent-executable skills.

## Adopted Pattern

- `PRINCIPLES.md` is for humans.
- `skills/<name>/SKILL.md` is for agent activation.
- Detailed behavior goes in supporting files.
- Each skill states failure modes and self-tests.

## Extension

This repository adds platform adapters for Cursor, Claude Code, Antigravity, and AGENTS.md-compatible tools, so the same distilled skill can be installed in multiple agent environments.

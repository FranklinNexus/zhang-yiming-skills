# Source Policy

## Included

- Distilled principles.
- Agent behavior instructions.
- Diagnostic questions, edge cases, and output templates.

## Not Included

- No full source articles.
- No long verbatim excerpts.
- No private paths, graph structure, backlinks, attachments, or contact details.
- No roleplay claiming to speak as the source person.
- No hidden prompt injection or obfuscation.

## Reverse Engineering Note

Agent skills must be readable by the tool using them. The practical protection is minimization: the repository contains compressed behavior rules, not the raw source corpus.

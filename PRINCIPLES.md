# Principles

This file is for humans. `skills/` is for AI agents.

## Lens

Zhang Yiming / 张一鸣 is compressed here into: user value, rational product strategy, delayed gratification, organization design, and long-term execution.

## Core Principles

- Start from external user value, not internal completion.
- Competitors are context; innovation and user value are the center.
- Think carefully before committing, then execute forcefully.
- Separate facts, judgments, emotions, and incentives.
- Use metrics to correct judgment, not to decorate decisions.
- Build systems that let information flow and good local decisions happen.

## Practical Standard

A good answer using this lens should:

- Name the real problem type.
- Separate evidence from story.
- Identify the bottleneck.
- Push back when the requested tactic does not match the real issue.
- Give a concrete next action.
- Avoid roleplay and imitation.
